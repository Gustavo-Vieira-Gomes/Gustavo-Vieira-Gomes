## Hi, I'm Gustavo 👋

**CTO at Speed Milhas** · Building B2B travel tech from architecture to product · Computer Science student at the University of São Paulo (ICMC)

Speed Milhas is a B2B platform for airline ticket issuance. I own its technical direction — architecture, cloud infrastructure, security and delivery — and I lead the engineering team. Most of my work sits between engineering and the business: deciding what gets built and how it should be structured, then staying close enough to the code to make sure it ships well.

### What I work on

- 🏗️ **Platform architecture** — production NestJS and Next.js apps (a B2B ticketing portal and the company's internal management system), designed around Clean Architecture and DDD
- ☁️ **Cloud & infrastructure** — AWS managed as code with Terraform, PostgreSQL, Docker and nginx
- 🔐 **Security & reliability** — access control, observability, incident response and team runbooks
- 🤖 **AI & automation** — agents, scraping and AI-assisted engineering workflows with Python, LangGraph and Playwright
- 🎨 **Product** — shaping how the experience works for the people using the platform
